============================================================
 ManakaMouseFix v0.14.0
 SecretFlasherManaka 16:10 屏幕（黑边 / 鼠标偏移）修复补丁
============================================================

【这个补丁解决什么问题】

SecretFlasherManaka（v1.1.3，Unity IL2CPP）在 16:10 比例的屏幕上
（例如 2560×1600、1920×1200 的显示器或笔记本）会出现：

  · 每次进入全屏、切回全屏、或应用图形设置后，游戏会把渲染分辨率
    切回它自己的 16:9 档位（2560×1600 屏上会切成 2560×1440）；
  · 画面于是按 16:9 居中渲染，屏幕上下各出现一条黑边
    （2560×1600 上每条约 80 像素）；
  · 同时所有坐标整体偏移，造成“鼠标指针和点击位置对不上”的错觉。

本补丁会自动把全屏分辨率强制回屏幕原生分辨率，黑边和偏移会在约
半秒内自动消失，全程无需手动操作（相当于自动帮你按了一次 F11）。

【依赖与兼容】

· 游戏：SecretFlasherManaka v1.1.3
· 框架：BepInEx 6.0.0-be（在 be.735 上测试通过）
· 测试环境：Windows 11，2560×1600 @150% 缩放
· 只对【全屏】模式生效；窗口模式完全不受影响。

【安装】

把本包里的
    BepInEx\plugins\ManakaMouseFix.dll
复制到游戏目录下的
    BepInEx\plugins\
（若没有 plugins 文件夹，请先正确安装 BepInEx 6）。
启动游戏即生效，无需其他设置。

【原理】

插件持续监测“全屏状态 + 当前渲染分辨率”，一旦发现当前不是屏幕
原生分辨率，立即调用 Unity 的 Screen.SetResolution 强制切回原生，
从而消除 16:9 letterbox 与由此产生的坐标偏移。不修改游戏本体文件。

【配置文件】

首次运行后生成：
    BepInEx\config\com.lolo.manaka.mousefix.cfg

[Repair]
AutoGuardFullscreenResolution = true
    核心开关：自动把非原生的全屏分辨率修正回原生（默认开启）。
    如果你确实想使用较低的全屏分辨率，可改为 false；
    改 false 后仍可用热键 F11 手动修正。
ReapplyResolutionOnStartup = false
    启动时是否自动修复“只渲染左上角”的旧故障（默认关闭，见 FAQ Q1）。
ReapplyDelaySeconds = 6
    上面那一项的启动延迟（秒）。
AddNativeResolutionToGameList = false
    实验性功能：向游戏的分辨率列表注入原生分辨率。
    （游戏设置界面并不读取该列表，一般无需开启。）

【诊断热键（平时用不到，排除问题时用）】

F8  = 把完整诊断信息写入日志（BepInEx\LogOutput.log）
F9  = 开关屏幕上的“幽灵光标”调试标记
F10 = 紧急解锁鼠标（万一鼠标被游戏锁死）
F11 = 手动强制原生分辨率（自动修复功能的手动版）
F6  = 只读探测游戏输入管理器（安全，不改动任何东西）
F7  = 只读探测游戏显示设置模块（安全，不改动任何东西）

【常见问题】

Q1：全屏后画面只显示左上角一块，其余区域黑屏？
A1：这是游戏自身的老毛病（上次以全屏退出后，本次启动恢复全屏
    失败所致），与本补丁无关。按一下 F11（或连按两次 Alt+Enter）
    即可恢复；退出游戏前先切回窗口模式，可显著降低它的出现概率。

Q2：游戏设置里依然找不到 2560×1600（或其他 16:10 分辨率）？
A2：正常现象。游戏只提供 16:9 / 21:9 两档，本补丁是在背后强制
    原生分辨率，不需要（也无法）在设置里选择它。

Q3：日志里出现很多 MM| 开头的行？
A3：那是插件的诊断输出，属于正常现象，无需理会。

Q4：装上后没感觉到任何变化？
A4：如果你平时用窗口模式游玩，本补丁不会做任何事（窗口模式本来
    就没有这个问题）；16:9 显示器也不会触发本问题。

【卸载】

删除 BepInEx\plugins\ManakaMouseFix.dll 即可；
配置文件可一并删除（BepInEx\config\com.lolo.manaka.mousefix.cfg）。
