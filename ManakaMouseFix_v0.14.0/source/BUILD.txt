构建说明（仅供参考，普通用户可忽略本文件）

目标框架：net6.0（.NET SDK 6.x）
工程结构：Plugin.cs + ManakaMouseFix.csproj
          工程同级需要一个 libs\ 文件夹，内含以下引用 DLL
          （从游戏的 BepInEx\core 与 BepInEx\interop 中提取）：

            BepInEx.Core.dll
            BepInEx.Unity.IL2CPP.dll
            Il2CppInterop.Runtime.dll
            Il2Cppmscorlib.dll
            Assembly-CSharp.dll
            UnityEngine.dll
            UnityEngine.CoreModule.dll
            UnityEngine.UI.dll
            UnityEngine.UIModule.dll
            UnityEngine.InputLegacyModule.dll
            UnityEngine.IMGUIModule.dll
            Unity.InputSystem.dll
            Unity.InputSystem.ForUI.dll

构建命令：
    dotnet build ManakaMouseFix.csproj -c Debug

产物：
    bin\Debug\net6.0\ManakaMouseFix.dll
    → 复制到游戏资料夹 BepInEx\plugins\ 即可。

提示：所有 Reference 均为 <Private>false</Private>，
      不会把游戏自身的 DLL 复制进输出目录。
